<objective>
Make the kanban interactive: drag a card between the 7 columns to move it through the funnel, persisted via the `mover_card_funil` RPC with an optimistic update and rollback-on-failure, and highlight stalled/overdue cards on load. This is the Core Value interaction — moving a card is how a rep updates status without opening a form.

Purpose: FUN-02/FUN-03 (role-scoped card movement) and FUN-09 (the visibility-of-what's-stuck highlight that directly targets the "esquecimento" failure mode the project exists to fix).
Output: dnd-kit drag wired to the board, `moverCard` action over the RPC, and the `lib/funil/staleness.ts` overdue/stalled logic feeding the card highlight.

**Flagged risk (research skipped this phase):** `@dnd-kit` has no prior usage anywhere in this codebase — this is the first drag-and-drop feature. The exact sensor/collision/`useDraggable`/`useDroppable` API must be confirmed against @dnd-kit's current docs (via Context7 if available) and the accessible reference implementation `Georgegriff/react-dnd-kit-tailwind-shadcn-ui` cited in `.planning/research/PITFALLS.md`. Budget extra time here; if a genuine API unknown blocks progress, note it in the SUMMARY rather than guessing silently.
</objective>
