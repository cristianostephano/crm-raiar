<objective>
Add the confirm-time write orchestration: a pure, unit-tested accounting helper (`lib/importacao/confirmar.ts`) that decides exactly which reviewed rows get inserted and why the rest are skipped, and the `confirmarLoteImportacao` Server Action that Supervisor-gates, re-runs the duplicate check at confirm time (D-02), calls the `importar_clientes_lote` RPC, and returns a `{ importados, puladas }` result for the summary screen.

Purpose: This is where IMP-06 ("uma linha ruim não trava o lote") and D-02 ("revalida duplicados na hora de confirmar") are enforced in application logic, and where the per-row Importar/Pular decisions become a concrete insert set. Keeping the accounting in a pure helper (like dedupe.ts / annotarLinha.ts) makes the exact skip/keep rules testable without a live Next.js request scope.
Output: `lib/importacao/confirmar.ts` + `tests/importacao/confirmar.test.ts` + `confirmarLoteImportacao` in `app/actions/importacao.ts`.
</objective>
