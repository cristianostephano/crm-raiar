## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Vendedor (autenticado) → updateListaValor / setListaValorAtivo | Tenta editar/desativar valores contornando a UI Supervisor-only |
| Client → input `nome` (edição) | Texto arbitrário na renomeação cruza para o servidor |
| UI → tabelas de lookup (soft-delete) | Risco de apagar de vez um valor ainda referenciado por clientes |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
