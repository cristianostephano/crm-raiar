## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| rendered UI -> authorization | What the component chooses to render is never the security control |
| Client Component -> server module graph | Anything a `"use client"` file imports can end up in the browser bundle |
| picker options -> RPC parameter | The chosen replacement id is attacker-controllable regardless of what the Select offered |
